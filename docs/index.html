Agare

召し上がれ

A Safari highlighter for your Mac.

Download the app, drag it into Applications, turn it on in Safari. Highlights stay on this machine unless you export them.

Download Agare for Mac

Gets Agare.app.zip from the latest GitHub Release.

Install

  1. Download Agare.app.zip and unzip it. You should see an app named Agare.
  2. Drag Agare into the Applications folder.
  3. Right-click Agare → Open (macOS asks once because it did not come from the App Store).
  4. In the Agare window, click Turn on in Safari… and switch Agare on.
  5. If Safari does not list it: Safari → Settings → Developer → Allow unsigned extensions, then try step 4 again.
