Keep the note.

A personal Safari highlighter. Six inks, a note in the same popup, and a switch for this page or this site. Nothing leaves the machine unless you export it.

Download agare-safari.zip GitHub repo

Install in Safari

  1. Unzip the package. You should see manifest.json.
  2. Xcode → New → Project → macOS → Safari Web Extension. Name it Agare.
  3. Replace Resources with the extension files (not docs/ or .github/).
  4. Run once, quit the placeholder window, then enable Agare in Safari → Settings → Extensions.

This GitHub repo

  1. Pages (this site): Settings → Pages → Deploy from branch → main / /docs.
  2. A Release (versioned zip): tag v1.0.0 and push it. The workflow attaches agare-safari.zip.
Agare is a play on 召し上がれ — meshiagare. Personal use, MIT licence. Highlights never leave the machine unless you export them.
