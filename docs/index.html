Agare: a Safari highlighter

召し上がれ!

Agare highlights what you select on a page. Highlights never leave the machine unless you export them.

Agare.app.zip from the latest GitHub Release.

Install

  1. Privacy & Security Unzip the latest release and drag Agare into Applications. Double-click it. If Mac says it can’t be opened: System Settings → Privacy & Security, scroll to the bottom, click Open Anyway, confirm, then open Agare again.
  2. Set up with Xcode First time on this Mac: in the Agare window, click Set up with Xcode… and confirm. The helper signs Agare with a free Apple Development certificate (your Apple ID in Xcode — no paid Developer Program), installs it, and registers it in Safari (Safari will quit once).
  3. Turn it on in Safari Safari → Settings → Extensions → turn on Agare. If it is missing, run Set up with Xcode again and wait for Safari to reopen.
