Open Agare

From the latest release: unzip, drag Agare into Applications, then do these two steps.

Open Anyway

Privacy & Security

Double-click Agare. If Mac says it can’t be opened, go to System Settings → Privacy & Security, scroll to the bottom, and click Open Anyway. Confirm, then open Agare again.

First time

Set up with Xcode

In the Agare window, click Set up with Xcode… (first time on this Mac). Confirm the prompts. The helper copies the project; the build happens in Xcode. Choose your Team, then press Run.

Turn it on in Safari

  1. Open Safari. Open Settings (press ⌘ and ,).
  2. Advanced — tick Show features for web developers. That adds a Developer tab.
  3. Developer — tick Allow unsigned extensions. Enter your password if asked.
  4. Extensions — turn on Agare.

If Agare is not in the list, quit Safari fully (Safari menu → Quit Safari), open Agare again, then check Extensions.
