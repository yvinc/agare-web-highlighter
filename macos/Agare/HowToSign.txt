Agare — only if Set up with Xcode could not finish by itself

The helper signs both Agare and AgareExtension with the Apple ID already in
Xcode → Settings → Accounts. You do not pay for a Developer Program.

If the helper said there is no Apple ID:
  1. Xcode → Settings (⌘,) → Accounts → + → Apple ID
  2. Sign in with your iCloud Apple ID
  3. Click Set up with Xcode again in the Agare window

If the helper built but Safari has no Agare:
  Safari → Settings → Extensions → turn on Agare

If the helper opened this project because the build failed:
  TARGETS → Agare → Signing & Capabilities → Team (your name)
  TARGETS → AgareExtension → the same Team
  Scheme: Agare > My Mac  →  press ▶ Run
