Agare — automatic Personal Team

Set up with Xcode opens the project and clicks:
  Team → [Your name] (Personal Team)
on both Agare and AgareExtension.

Allow Terminal (or iTerm) in:
  System Settings → Privacy & Security → Accessibility
the first time macOS asks.

Do not leave Team on red “Unknown Name (certificate ID)”.
That ID is a leftover Keychain cert, not your Personal Team.
