## Contributions:
This project welcomes contributions from various backgrounds and disciplines!
One of this project's main aims is to foster an inclusive and welcoming environment. 
The owner asks all contributors for respectful feedback and suggestions as an effort to maintain a harmonious positive community.

Please kindly note that the initial build of this project relies largely on vibecoding.

## Bug and feature requests:
If you notice a bug, or have a feature request,
please feel free to open up an issue
to let the project team know.

If you'd like to contribute a feature or bug fix,
you can fork this project's repo and submit a pull request.


## Code of conduct:
All contributors must abide by this project's [code of conduct](CODE_OF_CONDUCT.md).
